# Concordancia SPRO y comparación de dispositivos

La aplicación dispone de dos pestañas independientes: **Concordancia SPRO** y **Comparar dispositivos**.

Para comparar dos dispositivos, cargue registros con variables equivalentes, revise el solape temporal y ajuste el desfase si es necesario. Los resultados pueden incluir sesgo, MAE, RMSE, correlación y límites de acuerdo, según las variables disponibles.

La correlación no demuestra concordancia. Los errores de sincronización pueden afectar las diferencias observadas. Este módulo no constituye por sí mismo una validación científica.
