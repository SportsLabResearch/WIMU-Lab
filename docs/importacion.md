# Formatos e importación

WIMU-Lab trabaja con registros de WIMU y contempla soporte experimental para FIT, GPX, TCX y CSV.

## Procedimiento

1. Conserve una copia inalterada del archivo original.
2. Abra **Sesiones** y seleccione el registro.
3. Compruebe las variables detectadas y sus unidades.
4. Revise la duración, las marcas temporales y la existencia de coordenadas GPS.
5. Ejecute únicamente análisis compatibles con las variables presentes.

!!! warning "Compatibilidad"
    El reconocimiento de un formato no garantiza que todas las exportaciones de todos los fabricantes sean compatibles. Documente los errores de importación y compruebe los valores antes de interpretar resultados.
