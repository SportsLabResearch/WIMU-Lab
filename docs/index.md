# WIMU-Lab v1.2.0

**Manual técnico y científico** de WIMU-Lab, desarrollado en SportsLabResearch.

WIMU-Lab es una herramienta de investigación para el análisis temporal y espacial de registros de monitorización deportiva.

## Contenidos

- [Instalación y ejecución](instalacion.md)
- [Formatos e importación](importacion.md)
- [Gráficos y GPS](gps.md)
- [Calidad científica y limitaciones](metodologia.md)

!!! warning "Estado de validación"
    La versión 1.2.0 es experimental. La sincronización entre el gráfico temporal y el mapa GPS, algunas importaciones de dispositivos externos y la compilación autónoma de Windows requieren comprobación adicional.
