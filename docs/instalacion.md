# Instalación y ejecución

El código fuente de WIMU-Lab v1.2.0 está disponible en el [repositorio oficial](https://github.com/SportsLabResearch/WIMU-Lab).

## Windows

El repositorio contiene `INICIAR_WIMU_Lab.bat` para iniciar la aplicación y `COMPILAR_AUTONOMO_WINDOWS.bat` para intentar crear una distribución autónoma. La compilación y ejecución en Windows deben verificarse antes de considerarlas validadas.

## Python

Consulte `requirements.txt` para las dependencias del proyecto y `iniciar.py` como punto de entrada. No modifique los datos originales.

## Datos

Conserve los registros de entrada y los resultados fuera del directorio de la aplicación. Evite publicar sesiones identificables.
