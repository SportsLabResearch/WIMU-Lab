# Interfaz de WIMU-Lab

La navegación real de v1.2.0 utiliza los menús superiores **Archivo, Sesiones, Análisis, Informes, Ver y Ayuda** y las pestañas **Inicio, Sesiones, Jugadores, Análisis, Concordancia SPRO, Comparar dispositivos, Informes, Ajustes y Autores**.

**Inicio** resume las sesiones. **Sesiones** permite explorar registros. **Jugadores** gestiona las asignaciones. **Análisis** agrupa las operaciones estadísticas. **Informes** genera documentos. **Ajustes** configura las carpetas y preferencias.
